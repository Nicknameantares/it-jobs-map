# Карта ИТ-работодателей

Прямые ссылки на карьерные сайты 28 крупных ИТ-компаний России: экосистемы, маркетплейсы, банки, телеком, B2B SaaS, кибербезопасность и интеграторы.

**Сайт:** https://nicknameantares.github.io/it-jobs-map/

## Что умеет

- **Поиск по вакансиям всех компаний сразу**: введите должность — получите список со ссылками на сами вакансии. Фильтры по формату работы, городу и компании
- Вакансии собираются автоматически каждое утро (GitHub Actions, `tools/collect.py`) с открытых карьерных сайтов компаний в `data/vacancies.json`

- Схема компаний: ветка — сегмент рынка, станция — компания
- Фильтры по сегменту и разделу: ИТ, бизнес, стажировки, удалёнка
- Поиск своей роли на hh.ru сразу у каждого работодателя
- «Мой список» и статусы откликов (хранятся в браузере), выгрузка в CSV
- Таблица Excel со всеми ссылками и шаблоном трекера откликов

## Как предложить компанию или сообщить о битой ссылке

Откройте [issue](../../issues/new) или оставьте отзыв через форму на сайте.

Ссылки собраны по открытым источникам в октябре 2026 года.
